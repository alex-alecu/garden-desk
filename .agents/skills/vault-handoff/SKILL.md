# Hand Off Vault Desk Work

Produce:

```markdown
## Handoff

- Objective and current state (ready | not ready | blocked):
- Changed paths:
- Decisions and source links:
- Commands run and results:
- Open risks or questions:
- Next concrete action:
```

Separate verified facts from assumptions. Keep commands and failure messages only as far as needed to reproduce the next step. Never include secrets, customer documents, raw sensitive outputs, personal data, or hidden model reasoning. Do not commit, push, or open issues unless asked.
