---
name: review-report
description: A polished, executive-summary, or decision-ready report, DOCX, or PDF. Load after evidence only. Do not use for a bounded fact check or short review.
---

Cover scope, coverage, findings, evidence, gaps, actions, and limits; cite the source heading or table behind each one. Use no decorative scores, unsupported risk labels, or color-only meaning.

Write in Markdown. Deliver DOCX when the user names no format, and PDF only on request. Match headings, spacing, repeated headers, margins, and page numbers to the request.

Before you finish, reread and rederive the source facts behind every figure in the report rather than trusting an earlier draft; create or reopen every output file and verify its text, headings, tables, citations, page count, and metadata; state that a visual layout check still needs a person. This skill does not decide what the report recommends or verify a fact it did not itself derive from the source.
