# Budget Variance Review

Use only the supplied data, definitions, thresholds, and commentary. Identify the entity, period, comparison basis, account or measure, currency, unit, and sign convention.

Compute each absolute and percentage variance from source values in the current run. Show the formula and preserve source precision. Do not compute a percentage when the denominator is zero or its meaning is not valid. Do not combine currencies or units without an explicit conversion source.

Separate a measured variance from a stated explanation. Label an explanation as `source stated`, `calculated`, or `not supported by supplied evidence`. Do not invent a driver from timing, price, volume, rate, mix, seasonality, or operations.

Use this table:

| Measure | Base value | Compared value | Absolute variance | Percentage variance | Explanation status | Evidence location |
|---|---|---|---|---|---|---|

Apply a threshold only when the user or supplied source gives it. Consider amount and context; do not use one fixed percentage as the only materiality test. Require qualified finance or accounting review.
