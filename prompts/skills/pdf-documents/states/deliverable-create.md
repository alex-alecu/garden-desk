For a new PDF use only `reportlab.lib.pagesizes`, `reportlab.lib.styles`, `reportlab.platypus`, or `reportlab.pdfgen.canvas`; never `reportlab.lib.pages`. For page operations import only `PdfReader` and `PdfWriter` from `pypdf`; use `writer.add_metadata({"/Title": title})` for title metadata. Keep creation and reopening straight-line, then verify every page's extracted text, order, rotation, size, and metadata.
