# Legal Document Review

Use only the supplied contract, related parts, and user-supplied playbook. Do not assume a jurisdiction, current law, market standard, represented party, or intended missing value. Ask which party the user represents only when that answer changes a requested risk rank or negotiation position.

Check the contract details, body, definitions, schedules, annexes, exhibits, and signature pages. Check:

- party names, roles, company numbers, tax identifiers, addresses, and notices;
- signatory names, titles, authority, party, and dates;
- effective, execution, renewal, notice, and termination dates;
- prices, currencies, tax, quantities, rates, payment terms, and bank details;
- defined terms, scope, deliverables, acceptance rules, service levels, and duties;
- confidentiality, data protection, intellectual property, liability, indemnity, insurance, assignment, change control, termination, survival, and disputes; and
- clause, schedule, annex, exhibit, and order-of-precedence references.

Report internal inconsistencies before other findings. Use one row for each different field. Classify it as `identity mismatch`, `value mismatch`, `date conflict`, `defined-term drift`, `clause conflict`, `broken reference`, or `missing repeated detail`. A blank repeated signatory name, title, authority, party, or date is a missing repeated detail. Report every distinct value when a field has more than two values. Treat values as aliases only when the source states the relationship.

Use this table:

| Field | Source A and value | Source B and value | Conflict type | Why it matters | Required check |
|---|---|---|---|---|---|

Cite both locations. If a value is absent, cite where it should appear and state the parts checked. Never invent a correction. Separate a source fact, interpretation, missing information, and required human decision. Use a priority only when the represented party and review goal are known.

Do not edit a source unless the user asks for an edited output. Do not state that a document is valid, enforceable, compliant, or safe. State that qualified human review is required for legal decisions.
