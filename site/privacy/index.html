Privacy notice

Garden Desk is designed around local ownership. This notice separates the public website, the synthetic demo, and the desktop application so each boundary is clear.

The marketing website

This website has no accounts, analytics, tracking pixels, advertising, cookies, contact forms, or mailing list. Garden Desk does not receive visitor profiles or form submissions from it.

GitHub Pages hosts the static files. GitHub may process ordinary request information and hosting logs under GitHub’s privacy statement. That hosting activity is controlled by GitHub, not by application code on this site.

The interactive demo

The demo uses invented sample names, organizations, amounts, paths, and identifiers. Its composer is a local-only interface with no form action. Text entered there is not transmitted, uploaded, persisted, or stored in browser storage. Reloading resets the demo.

No model runs in the public demo. Guided examples use fixed results in browser memory, and any other prompt receives an immediate explanation of that limitation.

The desktop application

Garden Desk has no application telemetry: no analytics, crash reporting, or background metrics export. Local audit records remain on the owner’s computer unless the owner explicitly exports them. Selected source folders are presented read-only to the restricted work environment.

Your choices and contact

There is no website account or marketing profile to delete. For an ordinary privacy question, open a non-sensitive issue in the public issue tracker. Do not place private records or vulnerability details in a public issue.
