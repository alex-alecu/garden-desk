Privacy

Clear privacy practices, without hidden tracking.

This policy explains the public website and the privacy design of the Vault Desk desktop application.

Initial project policy · Last updated July 25, 2026

The website

The Vault Desk website does not offer accounts, forms, comments, payments, or mailing lists. It does not use analytics, advertising, tracking pixels, or cookies. The project does not receive personal information directly through this website.

The site is hosted by GitHub Pages. Like other web hosts, GitHub may process ordinary technical information in hosting logs, such as an IP address, browser details, and the pages requested. GitHub handles that information under its own privacy statement. The Vault Desk project does not add to or independently access those hosting logs.

The desktop application

Vault Desk is designed for local, offline work:

  • There is no application telemetry, analytics, or crash-reporting service.
  • Your selected source folders are mounted read-only.
  • Generated files are kept in a separate, controlled local workspace.
  • Local audit records remain local unless you explicitly export them.
  • There is no silent cloud fallback.

Files, conversations, generated output, and diagnostic snapshots may contain private information. You control them on your computer and should share them only through a channel you trust. Ordinary operating-system backup, synchronization, security, and deletion behavior remains under your control.

Third-party links

This website links to GitHub and may link to other external resources. Those services have their own privacy practices. Following an external link leaves the Vault Desk website.

Changes and contact

Material changes will be published on this page with an updated date. For an ordinary privacy question, open a non-sensitive GitHub issue. Do not post private documents, credentials, personal information, or suspected vulnerabilities in a public issue. Security concerns should follow the security reporting guidance.

This is an initial project policy. It should receive legal review before a company, paid service, personal-data collection, or formal release distribution is introduced.
