Privacy and security

Private is an architecture choice.

The desktop is designed to work locally and offline. Tools run inside a restricted environment with no network interface, while the application controls access and keeps a local record of what happened.

Security overview ↗ Privacy notice ↗

No application telemetry

Vault Desk does not send analytics, crash reports, or background usage metrics.

No host shell for generated work

Executable tasks are bounded inside a no-network virtual machine.

Local audit records stay local

Records are not transmitted unless the owner explicitly exports them.
