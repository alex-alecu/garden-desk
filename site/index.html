Privacy and security

Your work stays yours.

Vault Desk is built to work locally, with narrow access to the files you choose and no silent cloud fallback.

Read how the security model works
  • No application telemetry or background analytics.
  • Selected source folders are read-only.
  • Local audit records remain local unless you explicitly export them.
  • Generated work runs in a private, network-isolated workspace.
