Open model. Managed for you.

Gemma 4 runs entirely on your computer.

Vault Desk V1 is built around Gemma 4 12B QAT, an Apache-2.0 open model from Google. It is packaged with a pinned local runtime, so the model works offline without an account, API key, endpoint, or separate model server.

Gemma 4 is the V1 default, not a permanent lock-in. Vault Desk’s product contracts are model-agnostic, and we intend to keep the app current with the best open models as they are released—after each one passes the same privacy, quality, and hardware gates.

Privacy without an opt-out

We cannot track what we never collect.

Vault Desk tracks absolutely nothing about how you use the app. It contains no application analytics or telemetry pipeline. The desktop works locally and offline, while generated tools run inside a restricted environment with no network interface.
